# 🦌 Deer vs Antelope Binary Image Classifier

A CNN-based image classification web app that distinguishes between **Deer** and
**Antelope** images. Built with TensorFlow/Keras (transfer learning on
MobileNetV2) and deployed as an interactive Streamlit application.

This project was completed as part of a mini-project covering:
- CLO5: Designing, training, and evaluating deep learning architectures
- CLO7: Deploying a trained model as a cloud-based web app with Streamlit, using Git/GitHub
- CLO8: Documenting and communicating results as a team

## 📊 Dataset
Images of deer and antelope were collected for binary classification.
source: Kaggle '90 Different Animals' dataset. Place images into 
`data/train/<class>` and
`data/val/<class>` following the folder structure above before training.

## 🧠 Model
- **Architecture:** MobileNetV2 (pretrained on ImageNet) as a frozen feature
  extractor, followed by a GlobalAveragePooling layer, a Dense(128, ReLU) layer,
  Dropout(0.3), and a final Dense(1, sigmoid) output for binary classification.
- **Fine-tuning:** After initial training, the last 20 layers of the backbone
  are unfrozen and trained at a lower learning rate to improve accuracy.
- **Input size:** 224×224×3
- **Loss:** Binary cross-entropy | **Optimizer:** Adam


## ⚡ Deploy-First Workflow (recommended)

A working `model/deer_antelope_model.h5` **placeholder model is already included**
in this repo (generated by `make_placeholder_model.py`). It has the correct
architecture and input/output shape, but is untrained — its predictions are
meaningless (~50/50 guesses).

This lets you:
1. Push this repo to GitHub and deploy to Streamlit Cloud **immediately**,
   before your dataset or real training is ready.
2. Confirm the whole pipeline works end-to-end (repo structure, `requirements.txt`,
   Streamlit build, file upload, prediction display) so you catch any
   deployment issues.
3. Once `train_model.py` finishes producing the real trained model, just
   overwrite `model/deer_antelope_model.h5` (and `model/class_indices.json`)
   with the real files and `git push`. Streamlit Cloud auto-redeploys — no
   other changes needed, since `app.py` already points at that same path.

## 🚀 How to Run Locally

1. Clone this repository:
   ```bash
   git clone https://github.com/Confidence-247/deer-antelope-classifier.git
   cd <your-repo>
   ```
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. (Optional) Train the model yourself — requires the `data/` folder to be
   populated with images first:
   ```bash
   python train_model.py
   ```
   Or use the provided pretrained `model/deer_antelope_model.h5`.
4. Run the Streamlit app:
   ```bash
   streamlit run app.py
   ```
5. Open the local URL shown in the terminal (usually `http://localhost:8501`).


## ☁️ Deployment (Streamlit Community Cloud)

1. Push this project to a public GitHub repository (include the `model/`
   folder with the trained `.h5` file — use Git LFS if the file is large).
2. Go to [share.streamlit.io](https://share.streamlit.io) and sign in with GitHub.
3. Click **"New app"**, select your repository, branch, and set the main file
   path to `app.py`.
4. Click **Deploy**. Streamlit Cloud will install `requirements.txt`
   automatically and launch the app.
   

## 🖼️ Usage
1. Open the deployed app link.
2. Upload a `.jpg`, `.jpeg`, or `.png` image of a deer or antelope.
3. Click **Classify**.
4. The app displays the predicted class (Deer or Antelope) with a confidence score.
